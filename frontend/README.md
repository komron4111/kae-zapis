# Сайт (frontend)

Всё, что открывается в браузере и на телефоне: приложение Арай и страница для клиентов. GitHub Pages публикует эту папку по адресу https://komron4111.github.io/kae-zapis/. Данные сайт берёт с сервера из папки [backend](../backend/README.md).

| Файл | Что это |
|---|---|
| `index.html`, `app.js`, `style.css` | Приложение Арай |
| `okna/` | Страница для клиентов: свободное время, заявка, личная ссылка на запись |
| `logic.js` | Правила и расчёты: деньги, время, заявки, клиенты, копия. Этот же файл использует сервер |
| `zip.js` | Архив резервной копии |
| `config.js` | Адрес сервера |
| `sw.js`, `manifest.webmanifest`, `icons/` | Работа без интернета, уведомления, установка на телефон |
| `tests/` | Тесты `logic.js` и `zip.js` |

Сборки нет: файлы публикуются как есть.

## Как выпустить новую версию

1. Увеличьте `VERSION` в `sw.js` и `APP_VERSION` в `app.js`.
2. Выполните `git commit` и `git push`. GitHub сам выложит папку: вкладка Actions → «Сайт на GitHub Pages», обычно за 1–2 минуты.
3. На телефоне новая версия появится, когда приложение закроют смахиванием и откроют снова. Иногда это нужно сделать дважды.

Если изменился `logic.js`, выложите и сервер: он берёт правила из этого файла.

## Проверка на компьютере

1. В папке проекта запустите `python3 -m http.server 8765 -d frontend`.
2. Откройте http://localhost:8765/tests/ — тесты, или http://localhost:8765/ — приложение.

Чтобы приложение работало с локальным сервером, а не с настоящим, выполните в консоли браузера `localStorage['kae:api'] = 'http://127.0.0.1:8787'`.
