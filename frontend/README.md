# Сайт (frontend)

Всё, что открывается в браузере и на телефоне: приложение мастера Beautybook (до 2.4.0 — Nailapp), страница для клиентов и страница администратора. Папка публикуется на трёх адресах: основной — https://beautybook-kz.pages.dev/ (Cloudflare Pages, проект `beautybook-kz`, с 2.5.0), прежние — https://nailapp.pages.dev/ (проект `nailapp`) и https://komron4111.github.io/kae-zapis/ (GitHub Pages). Данные сайт берёт с сервера из папки [backend](../backend/README.md).

| Файл | Что это |
|---|---|
| `index.html`, `app.js`, `style.css` | Приложение мастера: вход и регистрация с анкетой и условиями подписки, записи, клиенты, финансы, настройки, чат с администратором. Темы: пурпурная, розово-чёрная (2.7.0, как фон значка; у «BB Админ» — всегда), розовая, фиолетовая и «Графит». Название в шапке — неоновое (`text-shadow`), как логотип |
| `okna/` | Страница для клиентов: свободное время, заявка, личная ссылка на запись — в теме мастера, с его направлением и Instagram. Мастер — из адреса: `okna/?m=<ссылка мастера>`, без `?m=` — Арай |
| `admin/` | Страница администратора (`manifest.webmanifest` — приложение «BB Админ» для экрана «Домой», `sw.js` — уведомления администратору, своя область `admin/`): мастера (сортировка, анкета, записи по месяцам), подписки (шкала, месяц или год), чат с мастерами, сервер (шкалы загрузки), сброс пароля, WhatsApp для «Забыли пароль?», вход по Face ID (спрашивается сразу при открытии) |
| `logic.js` | Правила и расчёты: деньги, время, заявки, клиенты, копия, ссылка мастера из имени, «растягивание» пароля, подписка и тариф «Про» (`TARIFF`, `TRIAL_DAYS`), направления (`SPECIALTIES`), числа записей для администратора (`statsPayload`). Этот же файл использует сервер |
| `zip.js` | Архив резервной копии |
| `config.js` | Адрес сервера (`API_URL`: на beautybook.kz — сам сайт, на прежних адресах — прежний адрес на Cloudflare, он пересылает запросы на свой сервер), основной адрес сайта для ссылок клиентов (`PUBLIC_URL` = https://beautybook.kz/) |
| `theme-init.js` | Тема и режим до первой отрисовки (отдельным файлом из-за политики безопасности) |
| `errors.js` | Ошибки страницы — в журнал на сервере (без личных данных, не больше 5 за открытие) |
| `phone-input.js` | Поле телефона: «+7» не стирается, номер разбивается пробелами |
| `i18n.js`, `kk.js` | Язык (2.7.0): русский или казахский. В коде тексты пишутся по-русски внутри `t('…', {подстановки})`; если выбран казахский, `t` берёт перевод из словаря `kk.js` («русская фраза → казахская», около 800 фраз: приложение, страница клиентов, администратор, ответы сервера). Нет перевода — остаётся русский. Язык — в `localStorage` (`kae:lang`), исходно — по языку телефона. Словарь берёт и сервер — для уведомлений |
| `install.js` | Кнопка «Установить на экран „Домой“» (с 2.6.0) для приложения мастера и «BB Админ»: на Android — окно браузера «Установить» (`beforeinstallprompt`), на iPhone и в браузерах без него — подсказка с шагами и стрелкой к нужной кнопке |
| `screenshots/` | Скриншоты для окна установки на Android (2.6.1): Chrome показывает их с описанием из `manifest.webmanifest`, как в магазине приложений. Сняты с демо-мастера на локальном сервере (вымышленные клиенты), 750×1624, JPEG |
| `sw.js`, `manifest.webmanifest`, `icons/` | Работа без интернета, уведомления (заявки, сообщения администратора, напоминания о записях — `kind: 'remind'`, по нажатию открывается день записи), установка на телефон. `icons/logo-neon.png` — неоновый логотип в шапке; `bb-*.png` — значки приложения мастера (тот же рисунок на розово-чёрном фоне), `bb-admin-*.png` — приложения администратора (с плашкой «АДМИН»). Исходник и мастерская значков — папка `design/` в корне проекта |
| `tests/` | Тесты `logic.js` и `zip.js` |

Сборки нет: файлы публикуются как есть.

## Перевод на казахский (с 2.7.0)

- Новый текст пишется по-русски внутри `t('…')`, а перевод добавляется в `kk.js` с тем же русским ключом. Меняется русский текст — меняется и ключ в `kk.js`.
- Числа и имена — подстановками: `t('Оплачено месяцев: {count} из 12', { count })`. В переводе те же `{…}`.
- В казахском окончание зависит от слова, поэтому даты и время с падежом готовит `logic.js`: `dateOn` («7 қазанда»), `dateUntil` («7 қазанға дейін»), `fullDate`, `fullDateOn`, `fullDateUntil` (с годом: «2026 ж. 7 қазан»), `dateRange` / `dateSpan` (срок), `timeTo` / `timeFrom` / `timeAt` («16:00-ге дейін», «14:30-дан», «9:15-те»). К именам, суммам и названиям (WhatsApp, Kaspi) окончания не приставляем — фразы построены так, чтобы они были не нужны («WhatsApp арқылы жазу», «{name}: төлем алынды»).
- Слово после числа: `L.plural(n, ['запись', 'записи', 'записей', 'жазылу'])` — четвёртое слово казахское (после числа оно не меняется).
- Кнопки телефона (iPhone, Android) в подсказках названы по-русски, как их обычно показывает телефон в Казахстане, с переводом в скобках: «Поделиться» («Бөлісу»).
- Тест «словарь» в `tests/` проверяет, что у каждого перевода те же подстановки.

## Безопасность

- **Политика безопасности (CSP)** — тег `<meta http-equiv="Content-Security-Policy">` в `index.html`, `okna/index.html` и `admin/index.html`. Скрипты — только файлы сайта, запросы — только к своему серверу. Сменился адрес сервера в `config.js` — поменяйте его и там.
- **Страница клиентов** показывает то, что прислал телефон мастера. Сервер пропускает расписание через `L.cleanSchedule` (даты, время, числа — строго своего вида), страница проверяет его ещё раз и экранирует всё, что выводит.
- **Код администратора** хранится только в памяти открытой страницы.

## Как выпустить новую версию

Выкладываем ночью, с 00:00 до 01:00 по Алматы (так написано мастерам в приложении).

1. Увеличьте `VERSION` в `sw.js` и `APP_VERSION` в `app.js`.
2. Основной адрес — свой сервер: `bash backend/deploy/deploy.sh` из папки проекта.
3. Прежние адреса beautybook-kz.pages.dev и nailapp.pages.dev. Из папки проекта (не из `backend`!) выполните обе команды:
   `~/.local/node/bin/node ~/.local/node/bin/wrangler pages deploy frontend --project-name beautybook-kz --branch main`
   `~/.local/node/bin/node ~/.local/node/bin/wrangler pages deploy frontend --project-name nailapp --branch main`
4. Прежний адрес komron4111.github.io: `git commit` и `git push`. GitHub сам выложит папку: вкладка Actions → «Сайт на GitHub Pages», обычно за 1–2 минуты.
5. Уведомление мастерам: `ssh beautybook /opt/beautybook/backend/deploy/notify-update.sh` (или «BB Админ» → «Уведомления» → «Отправить мастерам уведомление об обновлении»).
6. На телефоне новая версия скачается при следующем открытии; открытое приложение покажет баннер «Вышло обновление» с кнопкой «Обновить». Иначе — закрыть смахиванием и открыть снова, иногда дважды.

Команды `wrangler pages …` нельзя запускать из папки `backend`: новая версия wrangler берёт там настройки сервера и выкладывает сервер вместо сайта.

Если изменился `logic.js`, выложите и сервер: он берёт правила из этого файла.

## Проверка на компьютере

1. В папке проекта запустите `python3 -m http.server 8765 -d frontend`.
2. Откройте http://localhost:8765/tests/ — тесты, или http://localhost:8765/ — приложение.

Чтобы приложение работало с локальным сервером, а не с настоящим, выполните в консоли браузера `localStorage['kae:api'] = 'http://127.0.0.1:8787'`. **Сделайте это до регистрации**, иначе тестовый аккаунт появится на настоящем сервере. Страница администратора на компьютере — http://localhost:8765/admin/, код — `ACCESS_CODE` из `backend/.dev.vars`.
