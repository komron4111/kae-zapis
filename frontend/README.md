# Сайт (frontend)

Всё, что открывается в браузере и на телефоне: приложение мастера Beautybook (до 2.4.0 — Nailapp), страница для клиентов и страница администратора. Папка публикуется на двух адресах: основной — https://nailapp.pages.dev/ (Cloudflare Pages, проект `nailapp`), прежний — https://komron4111.github.io/kae-zapis/ (GitHub Pages). Данные сайт берёт с сервера из папки [backend](../backend/README.md).

| Файл | Что это |
|---|---|
| `index.html`, `app.js`, `style.css` | Приложение мастера: вход и регистрация с анкетой и условиями подписки, записи, клиенты, финансы, настройки, чат с администратором. Темы: пурпурная, розовая, фиолетовая и «Графит» |
| `okna/` | Страница для клиентов: свободное время, заявка, личная ссылка на запись — в теме мастера, с его направлением и Instagram. Мастер — из адреса: `okna/?m=<ссылка мастера>`, без `?m=` — Арай |
| `admin/` | Страница администратора: мастера (сортировка, анкета, записи по месяцам), подписки (шкала, месяц или год), чат с мастерами, сервер (шкалы загрузки), сброс пароля, WhatsApp для «Забыли пароль?», вход по Face ID (спрашивается сразу при открытии) |
| `logic.js` | Правила и расчёты: деньги, время, заявки, клиенты, копия, ссылка мастера из имени, «растягивание» пароля, подписка и тариф «Про» (`TARIFF`, `TRIAL_DAYS`), направления (`SPECIALTIES`), числа записей для администратора (`statsPayload`). Этот же файл использует сервер |
| `zip.js` | Архив резервной копии |
| `config.js` | Адрес сервера (`API_URL`), основной адрес сайта для ссылок клиентов (`PUBLIC_URL`) |
| `theme-init.js` | Тема и режим до первой отрисовки (отдельным файлом из-за политики безопасности) |
| `errors.js` | Ошибки страницы — в журнал на сервере (без личных данных, не больше 5 за открытие) |
| `phone-input.js` | Поле телефона: «+7» не стирается, номер разбивается пробелами |
| `sw.js`, `manifest.webmanifest`, `icons/` | Работа без интернета, уведомления, установка на телефон. `icons/logo-neon.png` — неоновый логотип в шапке, остальные значки — тот же рисунок на пурпурном фоне |
| `tests/` | Тесты `logic.js` и `zip.js` |

Сборки нет: файлы публикуются как есть.

## Безопасность

- **Политика безопасности (CSP)** — тег `<meta http-equiv="Content-Security-Policy">` в `index.html`, `okna/index.html` и `admin/index.html`. Скрипты — только файлы сайта, запросы — только к своему серверу. Сменился адрес сервера в `config.js` — поменяйте его и там.
- **Страница клиентов** показывает то, что прислал телефон мастера. Сервер пропускает расписание через `L.cleanSchedule` (даты, время, числа — строго своего вида), страница проверяет его ещё раз и экранирует всё, что выводит.
- **Код администратора** хранится только в памяти открытой страницы.

## Как выпустить новую версию

1. Увеличьте `VERSION` в `sw.js` и `APP_VERSION` в `app.js`.
2. Основной адрес. Из папки проекта (не из `backend`!) выполните:
   `~/.local/node/bin/node ~/.local/node/bin/wrangler pages deploy frontend --project-name nailapp --branch main`
3. Прежний адрес: `git commit` и `git push`. GitHub сам выложит папку: вкладка Actions → «Сайт на GitHub Pages», обычно за 1–2 минуты.
4. На телефоне новая версия появится, когда приложение закроют смахиванием и откроют снова. Иногда это нужно сделать дважды.

Команды `wrangler pages …` нельзя запускать из папки `backend`: новая версия wrangler берёт там настройки сервера и выкладывает сервер вместо сайта.

Если изменился `logic.js`, выложите и сервер: он берёт правила из этого файла.

## Проверка на компьютере

1. В папке проекта запустите `python3 -m http.server 8765 -d frontend`.
2. Откройте http://localhost:8765/tests/ — тесты, или http://localhost:8765/ — приложение.

Чтобы приложение работало с локальным сервером, а не с настоящим, выполните в консоли браузера `localStorage['kae:api'] = 'http://127.0.0.1:8787'`. **Сделайте это до регистрации**, иначе тестовый аккаунт появится на настоящем сервере. Страница администратора на компьютере — http://localhost:8765/admin/, код — `ACCESS_CODE` из `backend/.dev.vars`.
