# Значки Beautybook

Мастерская значков приложения (с 2.5.0). В сайт не входит.

- `neon-lines-512.png` — неоновый рисунок: белые линии на прозрачном фоне, вырезаны из прежнего значка.
- `make.js` — рисует значки: розовое свечение и фон. `ICONS` — какие файлы, какого размера и с каким фоном.
  Фоны (`BACKGROUNDS`): `corners` — приложение мастера (розово-чёрный), `edges` — администратор (тёмный центр, розовые края, плашка «АДМИН»).
- `save_server.py` — раздаёт эту папку и сохраняет готовые PNG в `out/`.

Как собрать:

1. В Терминале, из этой папки: `python3 save_server.py`
2. В браузере: http://127.0.0.1:8766/ → «Собрать значки».
3. Переложите файлы из `out/` в `frontend/icons/`. Если меняется рисунок или цвет, лучше дать файлам новые имена
   (и поменять их в `index.html`, `okna/index.html`, `admin/index.html`, обоих `manifest.webmanifest` и `sw.js`):
   iPhone долго помнит значок по старому имени файла.
