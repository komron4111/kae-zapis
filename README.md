# Записи Арай

Приложение на телефон для мастера маникюра: записи клиентов по дате и времени, прайс, остаток оплаты и финансы за месяц. Работает без интернета. Данные хранятся только в телефоне.

## Что умеет

- **Записи.** Календарь месяца, под ним клиенты выбранного дня по времени. Кнопка «+» добавляет запись. Если время уже занято, приложение предупредит.
- **Клиенты.** Имя и номер вводятся вручную один раз и сохраняются вместе с записью. В следующий раз нажмите «Выбрать клиента»: там список по алфавиту и поиск по имени или номеру. Сохранённые клиенты подсказываются и при вводе имени.
- **Услуга и деньги.** Наращивание, Маникюр, Снятие маникюра, Педикюр, Маникюр+Педикюр. Цена подставляется из прайса, её можно поменять. Вводите предоплату, и приложение показывает остаток.
- **Статус записи:** Записана, Оплачено, Отменена.
- **Звонок и напоминание.** Из записи можно позвонить клиенту или открыть WhatsApp с готовым текстом напоминания.
- **Финансы за месяц:** приход, расходы на материалы, аренда 70 000 ₸, чистая прибыль и сколько денег ещё должно прийти.
- **Резервная копия** в файл и восстановление из него.

## Как считаются деньги

- **Остаток** = сумма − предоплата.
- **Приход за месяц** — деньги, которые реально получены по записям этого месяца. У записей «Оплачено» считается вся сумма, у «Записана» и «Отменена» — только предоплата. Если предоплату вернули, поставьте в записи 0.
- **Ожидается ещё** — остатки по записям «Записана».
- **Чистая прибыль** = приход − материалы − аренда.
- **Аренда** берётся из «Настроек». Новая сумма действует с текущего месяца, прошлые месяцы не меняются.

## Первый запуск

1. Откройте адрес приложения на телефоне и установите его на главный экран:
   - **iPhone:** в Safari нажмите «Поделиться», затем «На экран „Домой“»;
   - **Android:** в Chrome нажмите «Установить» (или ⋮ → «Добавить на главный экран»).
2. «Настройки» → «Прайс»: впишите цены услуг.

## Где хранятся данные

Только в телефоне, в памяти браузера. Сервера нет, поэтому данные не видит никто, кроме Арай. Но если удалить приложение с экрана «Домой» на iPhone или очистить данные браузера, записи пропадут.

Поэтому раз в неделю: «Настройки» → «Сохранить копию» → отправьте файл себе в Telegram или WhatsApp. Если сменится телефон: установите приложение и нажмите «Настройки» → «Восстановить из копии». Приложение само напомнит о копии, если её не делали две недели.

## Как выпустить новую версию

1. После любой правки увеличьте `VERSION` в `sw.js` (например, `v1` → `v2`) и `APP_VERSION` в `app.js`.
2. Сохраните изменения в git и отправьте на GitHub (`git commit`, затем `git push`).
3. Через минуту GitHub Pages обновит сайт. Телефон подхватит новую версию при следующем запуске приложения.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Каркас страницы |
| `app.js` | Экраны, кнопки, хранение данных |
| `logic.js` | Расчёты: деньги, отчёт, телефоны, клиенты, резервная копия |
| `style.css` | Оформление, светлая и тёмная тема |
| `sw.js` | Работа без интернета |
| `manifest.webmanifest`, `icons/` | Название и иконка для установки на телефон |
| `tests/` | Тесты расчётов |

## Проверка на компьютере

В папке проекта запустите:

```bash
python3 -m http.server 8765
```

Приложение откроется по адресу http://localhost:8765, тесты — по адресу http://localhost:8765/tests/. Остановить сервер: Ctrl+C.
