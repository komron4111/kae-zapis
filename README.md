# Записи Арай

Приложение на телефон для мастера маникюра: записи клиентов, прайс, остаток оплаты, финансы, фото результата и онлайн-запись для клиентов по ссылке. Всё сохраняется в облако само. Если телефон потеряется, данные восстанавливаются по коду доступа.

## Адреса

- Приложение для Арай: **https://komron4111.github.io/kae-zapis/**
- Ссылка для клиентов: **https://komron4111.github.io/kae-zapis/okna/**

## Что умеет

- **Записи.** Календарь месяца, под ним записи выбранного дня, заявки клиентов и свободное время. Кнопка «+» добавляет запись.
- **Несколько услуг в одной записи.** Например, маникюр и педикюр. Сумма складывается из прайса сама, её можно поменять.
- **Рабочее время.** Запись можно начать с 9:00 до 20:00, между записями — 2 ч 30 мин. Если клиент записан на 12:00, следующему приложение предложит время не раньше 14:30, а до него — не позже 9:30. Часы и длительность меняются в «Настройках».
- **Закрытые дни.** Кнопка «Закрыть день для записи» — на отпуск или болезнь, можно сразу на несколько дней. Причину видит только мастер.
- **Клиенты.** Имя и номер вводятся один раз и сохраняются вместе с записью. На вкладке «Клиенты» — список с поиском и карточка клиента со всеми датами записей и фото результата.
- **Финансы за месяц:** приход, материалы, аренда, чистая прибыль и сколько денег ещё должно прийти.
- **Облако.** После каждого изменения записи, настройки и фото сами сохраняются в облако. Архив на телефон остался как дополнительная копия.

## Как клиент записывается

1. Клиент открывает ссылку (например, из профиля Instagram) и видит свободное время на 30 дней вперёд.
2. Выбирает день и время, вписывает имя и телефон, отмечает услуги (цены видны, сумма считается) и нажимает «Отправить заявку».
3. Это время сразу становится занятым для других клиентов.
4. Арай приходит уведомление «Новая заявка на запись». Она открывает заявку и видит имя, телефон, дату, время и услуги.
5. «Написать в WhatsApp» — откроется чат с готовым текстом с просьбой о предоплате.
6. Когда предоплата пришла, Арай нажимает «Подтвердить запись». Открывается готовая запись: остаётся вписать предоплату и сохранить. Запись появляется в календаре, а по ссылке это время остаётся занятым.
7. Открывается окно «Запись подтверждена». Кнопка «Отправить подтверждение в WhatsApp» открывает чат с клиентом и готовым сообщением: «Ваша запись подтверждена: 30 сентября в 12:00 (маникюр). Предоплата 5 000 ₸ получена. Ваша запись: <ссылка>». Остаётся нажать «Отправить».
8. «Отклонить» — если время не подходит. Тогда оно снова станет свободным для других клиентов.

Цены по ссылке всегда те же, что в прайсе приложения: изменения уходят на сайт автоматически.

## Личная ссылка клиента

По своей ссылке клиент в любое время видит свою запись:
- дату и время;
- услуги;
- стоимость, предоплату и сколько останется оплатить;
- статус: ждёт подтверждения, подтверждена, отменена или не принята.

Ссылка появляется, как только клиент отправил заявку (кнопка «Моя запись»). Подтверждение от Арай приходит с той же ссылкой.

- Страница меняется сама. Если Арай перенесёт запись, изменит услуги или предоплату, клиент увидит новые данные. Если Арай удалит запись или поставит «Отменена», клиент увидит «Запись отменена».
- Если клиент откроет общую ссылку с этого же телефона, вверху будет список «Мои записи».
- Для записи, которую Арай добавила сама, в окне записи есть кнопка «Отправить подтверждение»: она отправляет то же сообщение со ссылкой.
- Имя клиента видно только тому, у кого есть ссылка. Телефона клиента на этой странице нет.

## Первый запуск на телефоне Арай

1. Установите приложение на главный экран: в Safari нажмите «Поделиться», затем «На экран „Домой“».
2. «Настройки» → «Облако и заявки»: введите код доступа и нажмите «Подключить».
3. Там же нажмите «Включить уведомления» и разрешите их. На iPhone уведомления работают с iOS 16.4, когда приложение открыто с экрана «Домой».
4. «Настройки» → «Прайс»: проверьте цены. «Ссылка для клиентов»: впишите номер WhatsApp.

## Код доступа

Код доступа нужен, чтобы подключить телефон к облаку. **Запишите его и никому не показывайте.** С этим кодом можно увидеть записи и телефоны клиентов.

- **Новый телефон.** Установите приложение, введите тот же код — приложение предложит восстановить все записи и фото из облака.
- **Потерянный телефон** отключится сам, как только вы подключите новый: подключённым может быть только один телефон.
- **Сменить код.** В папке `backend` выполните `~/.local/node/bin/node ~/.local/node/bin/wrangler secret put ACCESS_CODE` и введите новый код. Уже подключённый телефон продолжит работать.

## Как считаются деньги

- **Остаток** = сумма − предоплата.
- **Приход за месяц** — деньги, которые реально получены по записям этого месяца. У записей «Оплачено» считается вся сумма, у «Записана» и «Отменена» — только предоплата. Если предоплату вернули, поставьте в записи 0.
- **Ожидается ещё** — остатки по записям «Записана».
- **Чистая прибыль** = приход − материалы − аренда.
- **Аренда** берётся из «Настроек». Новая сумма действует с текущего месяца, прошлые месяцы не меняются.

## Где хранятся данные

- **На телефоне.** Приложение работает и без интернета: всё сохраняется на телефоне и уходит в облако, когда появится связь.
- **В облаке Cloudflare:**
  - копия данных приложения (последние 30 версий) и фото;
  - свободное время для клиентов;
  - заявки клиентов — только пока Арай на них не ответила;
  - записи для личных ссылок клиентов: дата, время, имя, услуги, стоимость и предоплата, без телефона.
- **Удаление заявок.** После «Подтвердить» или «Отклонить» заявка удаляется с сервера. Старые заявки на прошедшие дни удаляются сами.
- **Удаление записей по личным ссылкам.** Через 60 дней после даты записи она удаляется с сервера сама, и ссылка перестаёт работать. В приложении Арай запись остаётся.

## Устройство проекта

Проект разделён на две части:

```
KAE_zapis/
├── frontend/   сайт: приложение Арай и страница для клиентов (GitHub Pages)
└── backend/    сервер на Cloudflare: заявки, уведомления, облако, личные ссылки
```

- **frontend** — всё, что открывается в браузере и на телефоне. Подробно — в [frontend/README.md](frontend/README.md).
- **backend** — сервер, с которым сайт обменивается данными по адресу `https://kae-zapis-api.kae-zapis.workers.dev/api/…`. Подробно — в [backend/README.md](backend/README.md).
- **Общие правила.** Свободное время и проверка заявки описаны в одном файле — `frontend/logic.js`. Сервер берёт его при выкладке, так что второй копии правил, которая могла бы разойтись с первой, нет.

## Как выпустить новую версию

- **Сайт:** `git push`. GitHub сам выложит папку `frontend/` (вкладка Actions → «Сайт на GitHub Pages»).
- **Сервер:** команда `wrangler deploy` в папке `backend/`.
- **`logic.js`:** если он изменился, выложите и сайт, и сервер.

Подробные шаги — в README каждой части.
