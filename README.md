# Beautybook

Приложение на телефон для мастеров красоты — маникюр, парикмахеры, барберы, брови и ресницы, визаж, косметология и другие (до версии 2.4.0 называлось Nailapp, до 1.4.0 — «Записи Арай»): записи клиентов, прайс, остаток оплаты, финансы, фото результата и онлайн-запись для клиентов по ссылке. С версии 2.0.0 в нём может работать много мастеров: у каждого свой аккаунт (номер телефона и пароль), свои данные и своя ссылка для клиентов. Всё сохраняется в облако само. Если телефон потеряется, мастер входит на новом по номеру и паролю, и данные возвращаются.

## Адреса

Основной адрес — **https://beautybook-kz.pages.dev/** (Cloudflare Pages, проект `beautybook-kz`, с 2.5.0; адрес `beautybook.pages.dev` был занят):

- Приложение для мастеров: **https://beautybook-kz.pages.dev/**
- Ссылка для клиентов — своя у каждого мастера: `https://beautybook-kz.pages.dev/okna/?m=<имя-в-ссылке>`. У Арай: **https://beautybook-kz.pages.dev/okna/?m=aray**. Ссылка без `?m=` (…/okna/) открывает запись к Арай.
- Страница администратора: **https://beautybook-kz.pages.dev/admin/** — её можно установить на экран «Домой» как отдельное приложение «BB Админ».

Прежние адреса тоже работают и выкладываются вместе с основным: https://nailapp.pages.dev/ (основной с 30.09 по 01.10.2026) и https://komron4111.github.io/kae-zapis/ (GitHub Pages, с него было установлено приложение у Арай). По ним открываются ссылки, которые клиенты уже получили. Приложение с любого адреса даёт клиентам ссылки на основной.

## Что умеет

- **Записи.** Календарь месяца, под ним записи выбранного дня, заявки клиентов и свободное время. Месяцы листаются стрелками или свайпом влево-вправо. Кнопка «+» добавляет запись.
- **Несколько услуг в одной записи.** Например, стрижка и укладка. Сумма складывается из прайса сама, её можно поменять.
- **Рабочее время.** Запись можно начать с 9:00 до 20:00. У каждой услуги в прайсе есть длительность, и время после записи освобождается по её услугам: после услуги на 30 минут в 12:00 следующая запись возможна с 12:30, после услуги на 2 ч 30 мин — с 14:30. Новая запись тоже должна успеть закончиться до следующей: приложение и страница для клиентов предупредят, если выбранные услуги не помещаются. Часы меняются в «Настройках».
- **Прайс.** Услуга, цена и длительность. С 2.5.0 новому мастеру прайс заполняется услугами его направления (маникюр, парикмахер, барбер, брови и ресницы, визаж, косметология, массаж, депиляция, тату и перманент — 7–12 услуг с длительностью); цены мастер вписывает сам. Если направление вписано своими словами, список подбирается по ключевым словам («Барбер, мужские стрижки» — барбер), а незнакомое направление начинает с пустого прайса. Пока прайс пуст, услугу в записи мастер вписывает словами, а клиент по ссылке — в поле «Что будем делать».
- **Закрытые дни и закрытое время.** Под записями дня — кнопки «Закрыть день» (отпуск, болезнь) и «Закрыть время» (с 2.3.0): например, 1 октября с 14:00 до 16:00 — к врачу. Можно сразу на несколько дней: тогда время закрыто в каждый из них. Закрытое время стоит в списке дня среди записей («14:00 Закрыто до 16:00»), в календаре у такого дня штриховка снизу. Для клиентов оно занято, как запись: по ссылке его не предложат, и услугу, которая не успеет закончиться до него, тоже. Окно подсказывает, сколько свободного времени останется, и предупреждает о записях, которые уже стоят на это время. Причину видит только мастер.
- **Клиенты.** Имя и номер вводятся один раз и сохраняются вместе с записью. Клиента можно добавить и без записи — кнопкой «+» на вкладке «Клиенты»; его можно удалить, пока у него нет записей. В карточке клиента — Instagram (открывается в приложении Instagram), день рождения (с возрастом и «через сколько дней») и откуда пришёл клиент; «Изменить» в карточке или сразу при добавлении. На вкладке «Клиенты» — список с поиском и карточка клиента со всеми датами записей и фото результата. Фото открываются на весь экран: свайп влево-вправо — следующее или предыдущее фото клиента, свайп вверх или вниз — закрыть. Двумя пальцами фото можно увеличить или уменьшить — после того как пальцы отпущены, оно возвращается к обычному размеру.
- **Финансы за месяц:** приход, материалы, аренда, чистая прибыль и сколько денег ещё должно прийти. Месяцы листаются стрелками или свайпом влево-вправо.
- **Страница для клиентов и личная ссылка** — шапка как в приложении: неоновый логотип и «Beautybook»; имя мастера и его направление — в заголовке («Запись к мастеру Арай», ниже «Маникюр и педикюр»), рядом кнопки «Открыть в 2ГИС» и Instagram. Цвета страницы — как у темы, выбранной в приложении мастера.
- **Оплата аренды.** «Настройки» → «Аренда»: месяцы года, у каждого — отмечена ли оплата и когда. Нажмите на месяц, чтобы отметить оплату с датой или снять отметку. То же — нажатием на строку «Аренда» в «Финансах».
- **Телефон клиента.** «+7» в поле стоит всегда, номер сам разбивается пробелами: «+7 700 000 00 00». Так же — на странице для клиентов.
- **Оформление.** Верхняя и нижняя полосы — стеклянные, в цвете темы. Исходная тема — пурпурная, в светлом режиме; в «Настройках» → «Оформление» можно выбрать розовую, фиолетовую или «Графит» (с 2.4.0: тёмно-серая со стальным синим, без розового — для барберов и парикмахеров). Клиенты видят страницу записи в той же теме. Кнопка с луной вверху справа включает тёмный режим (для вечера), с солнцем — возвращает светлый. Значок на экране «Домой» — тот же неоновый рисунок, что в шапке, на розово-чёрном фоне (с 2.5.0; у приложения администратора — с плашкой «АДМИН»).
- **Настройки.** Сначала список пунктов с коротким описанием, каждый пункт открывается отдельно; «‹ Настройки», свайп вправо или вкладка «Настройки» возвращают к списку.
- **Облако.** После каждого изменения записи, настройки и фото сами сохраняются в облако. Архив на телефон остался как дополнительная копия.
- **Аккаунт.** «Настройки» → «Аккаунт»: имя, номер для входа, подписка и её условия, «Сменить пароль» и «Выйти из аккаунта». Карточка «Анкета» (с 2.4.0): направление, номер Kaspi для счёта за подписку и Instagram (по нему клиенты переходят со страницы записи).
- **Чат с администратором** (с 2.4.0). «Настройки» → «Чат с администратором»: вопросы по оплате, подписке и работе приложения. Ответ администратора приходит уведомлением, число непрочитанных видно на вкладке «Настройки». Чат открывается и из окна «Продлите подписку».
- **Где вы принимаете.** Там же, в «Аккаунте», — адрес и ссылка на место в 2ГИС (в 2ГИС: «Поделиться» → «Копировать ссылку»). Клиенты видят адрес и кнопку «Открыть в 2ГИС» на странице записи и в своей личной ссылке, администратор — в списке мастеров. Подходят только ссылки 2ГИС.

## Как клиент записывается

1. Клиент открывает ссылку мастера (например, из профиля Instagram) и видит его свободное время на 30 дней вперёд.
2. Выбирает день и время, вписывает имя и телефон, отмечает услуги (цены видны, сумма считается) и нажимает «Отправить заявку».
3. Это время сразу становится занятым для других клиентов.
4. Мастеру приходит уведомление «Новая заявка на запись». Он открывает заявку и видит имя, телефон, дату, время и услуги.
5. «Написать в WhatsApp» — откроется чат с готовым текстом с просьбой о предоплате.
6. Когда предоплата пришла, мастер нажимает «Подтвердить запись». Открывается готовая запись: остаётся вписать предоплату и сохранить. Запись появляется в календаре, а по ссылке это время остаётся занятым.
7. Открывается окно «Запись подтверждена». Кнопка «Отправить подтверждение в WhatsApp» открывает чат с клиентом и готовым сообщением: «Ваша запись подтверждена: 30 сентября в 12:00 (стрижка). Предоплата 5 000 ₸ получена. Ваша запись: <ссылка>». Остаётся нажать «Отправить».
8. «Отклонить» — если время не подходит. Тогда оно снова станет свободным для других клиентов.

Цены по ссылке всегда те же, что в прайсе приложения: изменения уходят на сайт автоматически.

## Личная ссылка клиента

По своей ссылке клиент в любое время видит свою запись:
- дату и время;
- услуги;
- стоимость, предоплату и сколько останется оплатить;
- статус: ждёт подтверждения, подтверждена, отменена или не принята.

Ссылка появляется, как только клиент отправил заявку (кнопка «Моя запись»). Подтверждение от мастера приходит с той же ссылкой.

- Страница меняется сама. Если мастер перенесёт запись, изменит услуги или предоплату, клиент увидит новые данные. Если мастер удалит запись или поставит «Отменена», клиент увидит «Запись отменена».
- Если клиент откроет ссылку мастера с этого же телефона, вверху будет список «Мои записи» к этому мастеру.
- Для записи, которую мастер добавил сам, в окне записи есть кнопка «Отправить подтверждение»: она отправляет то же сообщение со ссылкой.
- Имя клиента видно только тому, у кого есть ссылка. Телефона клиента на этой странице нет.

## Аккаунты мастеров

- **Регистрация.** Мастер открывает приложение, нажимает «Создать аккаунт» и вписывает имя, номер телефона, своё направление (кнопками-подсказками или своими словами), номер Kaspi, на который администратор выставит счёт за подписку, Instagram (необязательно), адрес, где принимает, ссылку на своё место в 2ГИС и пароль (не короче 6 символов), который придумывает сам. Внизу — «Условия подписки» и галочка «Согласен(на) с условиями подписки»; без неё аккаунт не создаётся. Имя видят клиенты («Запись к мастеру …»), из него же получается ссылка для клиентов: «Мадина» → `okna/?m=madina`. SMS нет: номер — это логин.
- **Номер телефона** вводится так же, как у клиентов: «+7» стоит всегда, остальное само разбивается пробелами.
- **Вход** — по номеру и паролю. Один аккаунт — один телефон: если войти на новом телефоне, прежний (например, потерянный) выходит сам. На новом телефоне приложение возьмёт копию из облака.
- **Сменить пароль:** «Настройки» → «Аккаунт» → «Сменить пароль». Нужен текущий пароль.
- **Выйти:** «Настройки» → «Аккаунт» → «Выйти из аккаунта». Сначала всё сохраняется в облако, потом данные удаляются с телефона: на нём может войти другой мастер.
- **Забыли пароль?** Пароль восстанавливает администратор (см. ниже). Кнопка «Забыли пароль?» на экране входа открывает WhatsApp администратора с готовым сообщением и номером мастера.
- **Пароль не уходит на сервер.** Телефон превращает его в длинный ключ (PBKDF2, 200 000 шагов), и сервер хранит только отпечаток этого ключа. Даже администратор пароля не видит.

### Подписка (с 2.2.0, тариф «Про» — с 2.4.0)

- **Первые 7 дней** после регистрации — бесплатно, со всеми возможностями (с 2.4.0; раньше — месяц). У мастеров, зарегистрированных раньше, их периоды не меняются.
- **Тариф «Про»:** 2 990 ₸ в месяц или 29 900 ₸ в год. Оплата — счётом в Kaspi.kz на номер Kaspi из анкеты мастера; счёт выставляет администратор.
- **Даты.** Месяц — с даты по день перед тем же числом следующего месяца (30 сентября — 29 октября), год — 12 таких месяцев. Даты мастер видит в «Настройки» → «Аккаунт», там же «Условия подписки».
- **За 3 дня** до конца приложение предупреждает: «Подписка заканчивается … — продлите её у администратора» с кнопкой «Продлить» (WhatsApp администратору).
- **На следующий день после окончания** приложение закрывается окном «Продлите подписку»: тариф, «Чат с администратором», WhatsApp администратора и «Я оплатил(а) — проверить». Данные мастера не удаляются. Страница записи для его клиентов временно показывает «онлайн-запись недоступна, напишите мастеру», а личные ссылки клиентов на уже сделанные записи работают.
- **Продление — у администратора**, раздел «Подписки» (см. ниже). Доступ продлевается от конца текущего периода, а если он уже закончился, — с сегодняшнего дня; приложение мастера сразу откроется.

### Мастера после обновления до 2.4.0

У мастеров, зарегистрированных раньше (и у Арай), при первом запуске 2.4.0 откроется «Дополните анкету»: направление, номер Kaspi (подставлен номер входа, его можно поменять), Instagram и согласие с условиями подписки. Записи, клиенты, прайс и ссылка остаются. Надпись под иконкой на iPhone станет «Beautybook», только если иконку удалить и добавить на экран «Домой» заново (данные потом вернутся входом по номеру и паролю).

### Арай после обновления до 2.0.0

Все её записи, клиенты и ссылка остаются. При первом запуске новой версии приложение покажет «Ваш аккаунт»: Арай вписывает свой номер и придумывает пароль. Дальше она входит, как все мастера. Её ссылка для клиентов — `okna/?m=aray`, старая `okna/` тоже работает.

## Администратор

Администратор (диспетчер) видит всех мастеров, их подписки и записи, переписывается с мастерами и восстанавливает забытые пароли. Страница разложена по разделам, как «Настройки» в приложении: «Мастера», «Подписки», «Чат с мастерами», «Сервер», «WhatsApp для мастеров», «Вход по Face ID». В раздел проваливаешься нажатием, назад — «‹» вверху или свайпом вправо в Safari.

1. Откройте https://beautybook-kz.pages.dev/admin/ (удобнее — с иконки «BB Админ»: кнопка «Установить «BB Админ» на экран „Домой“» под формой входа). Если на этом устройстве включён вход по Face ID, он спрашивается сразу при открытии страницы; иначе — введите код администратора (маленькая кнопка «Войти по Face ID» — под «Войти»). Код нигде не сохраняется: после перезагрузки страницы его нужно ввести снова. Пока отдельный код не задан, подходит прежний код доступа (`ACCESS_CODE`).
2. **Мастера** — список с поиском по имени, направлению, номеру или адресу и сортировкой: «Новые», «Записи» (принятые за месяц), «По ссылке» (принятые из заявок со страницы клиентов), «Клиенты» (сколько клиентов в базе мастера); месяц листается стрелками. Нажатие открывает карточку мастера: направление, телефон, номер Kaspi с кнопкой «скопировать» (10 цифр — так их вставляют в счёт Kaspi), клиентов в базе, дата регистрации, адрес, кнопки 2ГИС, Instagram и «Написать» (чат), таблица «Записи по месяцам» (записей, заявок по ссылке и сколько из них принято, внёс сам), ссылка для клиентов, подписка, место на сервере и «Сбросить пароль». Откуда пришла запись, приложение помечает с 2.4.0: более ранние записи считаются внесёнными самим мастером.
   **Подписки** — календарь по месяцам, сортировка «По регистрации» или «По остатку подписки» (у кого кончается раньше — сверху). Под каждым мастером шкала из 10 овалов от красного к зелёному: каждый овал — 3 дня из последних 30, чем ближе конец, тем меньше их горит и тем они краснее. Галочка «оплата получена» спрашивает срок — «Месяц · 2 990 ₸» или «Год · 29 900 ₸»; снять галочку — отменить последнюю оплату. Вверху — сколько мастеров оплатили и сколько получено за месяц. В карточке мастера — «Оплата за месяц», «Оплата за год», все периоды с суммами, «Сделать доступ бессрочным» и «Доступ до» (дата вручную).
   **Чат с мастерами** — переписки с числом непрочитанных; ответ приходит мастеру уведомлением. Написать первым — кнопка «Написать» в карточке мастера.
   **Уведомления** (с 2.5.0) — на телефон администратора, даже когда страница закрыта: мастер написал в чат, зарегистрировался новый мастер, мастер нажал «Я оплатил(а)» в окне «Продлите подписку» (с номером Kaspi — проверьте оплату и поставьте галочку), а каждое утро в 9:00 — у кого подписка кончается сегодня или завтра и у кого закончилась вчера. Включаются кнопкой «Включить уведомления на этом устройстве»; на iPhone — только в приложении «BB Админ» с экрана «Домой» (iOS 16.4+). Там же «Прислать пробное уведомление» и список устройств. Нажатие на уведомление открывает нужное: чат с мастером, его карточку или «Подписки».
   **Сервер** — шкалы загрузки бесплатного тарифа (зелёные — запас большой, красные — подходим к пределу): база из 500 МБ, запросы к серверу, записанные и прочитанные строки за сутки, мастера (на 30 решаем про платный тариф); общая загрузка — низкая, средняя или высокая. Суточные цифры приносит проверка сервера по расписанию (9:00, 15:00, 21:00). Ниже — мастера по занятому месту.
3. **Сбросить пароль** (в карточке мастера). Страница придумает временный пароль и покажет его один раз. Кнопка «Отправить в WhatsApp» откроет чат с мастером и готовым сообщением. Мастер сразу выходит из приложения, входит с временным паролем и меняет его в «Настройки» → «Аккаунт».
4. **Ваш WhatsApp для мастеров.** Впишите свой номер: на него мастера пишут через «Забыли пароль?».
5. **Вход по Face ID.** Войдите один раз по коду и нажмите «Включить вход по Face ID на этом устройстве» (раздел «Вход по Face ID»). Дальше на этом телефоне Face ID спрашивается сразу при открытии страницы, а если не сработал или его отменили — есть маленькая кнопка «Войти по Face ID» под «Войти» и код-пароль телефона. Ключ хранится в «Связке ключей» Apple и появится на других ваших устройствах Apple (Mac — по Touch ID или паролю Mac). Вход действует, пока страница открыта (до 12 часов). Потеряли телефон — войдите по коду и нажмите «Убрать» у этого устройства. Ключ привязан к адресу: на beautybook-kz.pages.dev, nailapp.pages.dev и прежнем адресе он у каждого свой — на новом адресе Face ID включается заново.

**Код администратора — отдельный от всех паролей. Запишите его и никому не показывайте.** С ним можно сбросить пароль любому мастеру. Задать или сменить код: в папке `backend` выполните `~/.local/node/bin/node ~/.local/node/bin/wrangler secret put ADMIN_CODE` и введите новый код (не короче 8 символов).

## Первый запуск на телефоне мастера

1. Установите приложение на главный экран: на первом экране есть кнопка **«Установить на экран „Домой“»** (с 2.6.0; она же — баннер после входа и пункт в «Настройках»). На Android она сразу открывает окно браузера «Установить» — с 2.6.1 «как в магазине приложений»: описание и пять скриншотов Beautybook. На iPhone сайт не может установить себя сам (так устроен iOS) — кнопка показывает подсказку из трёх шагов со стрелкой к нужной кнопке Safari: «Поделиться» (на iOS 26 — сначала «•••») → «На экран „Домой“» → «Добавить». Если ссылка открыта внутри Instagram, WhatsApp или Telegram, подсказка попросит открыть её в Safari или Chrome и даст скопировать ссылку. На iPhone лучше сначала установить, а аккаунт создать уже в приложении с иконки: у приложения с экрана «Домой» свои данные.
2. Нажмите «Создать аккаунт» (или «Войти», если аккаунт уже есть).
3. «Настройки» → «Облако и заявки»: нажмите «Включить уведомления» и разрешите их. На iPhone уведомления работают с iOS 16.4, когда приложение открыто с экрана «Домой».
4. «Настройки» → «Прайс»: добавьте свои услуги — название, цену и сколько длится. «Ссылка для клиентов»: впишите номер WhatsApp и скопируйте ссылку в профиль Instagram.

## Как считаются деньги

- **Остаток** = сумма − предоплата.
- **Приход за месяц** — деньги, которые реально получены по записям этого месяца. У записей «Оплачено» считается вся сумма, у «Записана» и «Отменена» — только предоплата. Если предоплату вернули, поставьте в записи 0.
- **Ожидается ещё** — остатки по записям «Записана».
- **Чистая прибыль** = приход − материалы − аренда.
- **Аренда** берётся из «Настроек». Новая сумма действует с текущего месяца, прошлые месяцы не меняются.

## Где хранятся данные

- **На телефоне.** Приложение работает и без интернета: всё сохраняется на телефоне и уходит в облако, когда появится связь.
- **В облаке Cloudflare:**
  - копия данных приложения (последние 30 версий) и фото;
  - аккаунты мастеров: имя, номер, ссылка и отпечаток пароля (сам пароль — нет);
  - свободное время для клиентов;
  - заявки клиентов — только пока мастер на них не ответил;
  - записи для личных ссылок клиентов: дата, время, имя, услуги, стоимость и предоплата, без телефона;
  - анкета мастера: направление и номер Kaspi (видит только администратор), Instagram — в ссылке для клиентов;
  - переписка мастера с администратором;
  - числа записей мастера по месяцам для администратора — только числа (сколько записей, сколько по ссылке, сколько клиентов), без имён и телефонов.
- **Удаление заявок.** После «Подтвердить» или «Отклонить» заявка удаляется с сервера. Старые заявки на прошедшие дни удаляются сами.
- **Удаление записей по личным ссылкам.** Через 60 дней после даты записи она удаляется с сервера сама, и ссылка перестаёт работать. В приложении мастера запись остаётся.
- **Данные мастеров не смешиваются:** каждый мастер видит только свои записи, заявки, копию и фото.

## Устройство проекта

Проект разделён на две части:

```
KAE_zapis/
├── frontend/   сайт: приложение мастера, страница для клиентов, страница администратора (GitHub Pages)
└── backend/    сервер на Cloudflare: аккаунты, заявки, уведомления, облако, личные ссылки
```

- **frontend** — всё, что открывается в браузере и на телефоне. Подробно — в [frontend/README.md](frontend/README.md).
- **backend** — сервер, с которым сайт обменивается данными по адресу `https://kae-zapis-api.kae-zapis.workers.dev/api/…`. Подробно — в [backend/README.md](backend/README.md).
- **Общие правила.** Свободное время и проверка заявки описаны в одном файле — `frontend/logic.js`. Сервер берёт его при выкладке, так что второй копии правил, которая могла бы разойтись с первой, нет.

## Как выпустить новую версию

- **Сайт на основном адресе** (beautybook-kz.pages.dev) и на nailapp.pages.dev: команда `wrangler pages deploy` из папки проекта для каждого из двух проектов (см. [frontend/README.md](frontend/README.md)).
- **Сайт на прежнем адресе:** `git push`. GitHub сам выложит папку `frontend/` (вкладка Actions → «Сайт на GitHub Pages»).
- **Сервер:** команда `wrangler deploy` в папке `backend/`.
- **`logic.js`:** если он изменился, выложите и сайт, и сервер.

Подробные шаги — в README каждой части.
