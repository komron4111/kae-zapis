# Записи Арай

Приложение на телефон для мастера маникюра: записи клиентов по дате и времени, прайс, остаток оплаты и финансы за месяц. Работает без интернета. Данные хранятся только в телефоне.

## Что умеет

- **Записи.** Календарь месяца, под ним клиенты выбранного дня по времени и свободное время. Кнопка «+» добавляет запись.
- **Рабочее время.** Запись можно начать с 9:00 до 20:00, между записями — 2 ч 30 мин. Если клиент записан на 12:00, следующему приложение предложит время не раньше 14:30, а до него — не позже 9:30. Часы и длительность меняются в «Настройках».
- **Закрытые дни.** Кнопка «Закрыть день для записи» — на отпуск или болезнь, можно сразу на несколько дней. Причину видит только мастер.
- **Клиенты.** Имя и номер вводятся вручную один раз и сохраняются вместе с записью. В следующий раз нажмите «Выбрать клиента» или начните вводить имя. На вкладке «Клиенты» — список с поиском и карточка каждого клиента со всеми датами записей.
- **Фото результата.** В карточке клиента у каждого прошедшего визита кнопка «Фото». Фото уменьшаются до 1280 px, чтобы не занимать много места.
- **Ссылка для клиентов.** Клиенты видят по ссылке свободное время на 30 дней вперёд и нажимают на время — открывается WhatsApp с готовым сообщением. Имена, телефоны и причины закрытых дней клиентам не видны.
- **Услуга и деньги.** Наращивание, Маникюр, Снятие маникюра, Педикюр, Маникюр+Педикюр. Цена подставляется из прайса, её можно поменять. Вводите предоплату, и приложение показывает остаток.
- **Статус записи:** Записана, Оплачено, Отменена.
- **Звонок и напоминание.** Из записи можно позвонить клиенту или открыть WhatsApp с готовым текстом напоминания.
- **Финансы за месяц:** приход, расходы на материалы, аренда 70 000 ₸, чистая прибыль и сколько денег ещё должно прийти.
- **Резервная копия** — один архив со всеми записями и фото, и восстановление из него.

## Как считаются деньги

- **Остаток** = сумма − предоплата.
- **Приход за месяц** — деньги, которые реально получены по записям этого месяца. У записей «Оплачено» считается вся сумма, у «Записана» и «Отменена» — только предоплата. Если предоплату вернули, поставьте в записи 0.
- **Ожидается ещё** — остатки по записям «Записана».
- **Чистая прибыль** = приход − материалы − аренда.
- **Аренда** берётся из «Настроек». Новая сумма действует с текущего месяца, прошлые месяцы не меняются.

## Как подключить ссылку для клиентов (один раз)

Чтобы ссылка обновлялась сама, приложению нужен ключ GitHub с доступом только к репозиторию `kae-zapis-okna`.

1. В приложении откройте «Настройки» → «Ссылка для клиентов» и нажмите «Откройте страницу создания ключа». Войдите в GitHub.
2. Название, срок («без срока») и право «Contents: Read and write» уже заполнены. В разделе «Repository access» выберите «Only select repositories» → `kae-zapis-okna`.
3. Нажмите «Generate token», скопируйте ключ, вставьте в приложение и нажмите «Подключить».
4. Впишите номер WhatsApp, на который клиенты будут писать.

Ключ хранится только в телефоне и в резервную копию не попадает. Если телефон потерялся, удалите ключ на странице github.com → Settings → Developer settings → Personal access tokens.

## Первый запуск

1. Откройте адрес приложения на телефоне и установите его на главный экран:
   - **iPhone:** в Safari нажмите «Поделиться», затем «На экран „Домой“»;
   - **Android:** в Chrome нажмите «Установить» (или ⋮ → «Добавить на главный экран»).
2. «Настройки» → «Прайс»: впишите цены услуг.
3. Подключите ссылку для клиентов (см. выше).

## Где хранятся данные

Только в телефоне, в памяти браузера. Сервера нет, поэтому данные не видит никто, кроме Арай. Но если удалить приложение с экрана «Домой» на iPhone или очистить данные браузера, записи пропадут.

Поэтому раз в неделю: «Настройки» → «Сохранить копию» → отправьте файл-архив себе в Telegram или WhatsApp. В архиве все записи, настройки и фото. Если сменится телефон: установите приложение и нажмите «Настройки» → «Восстановить из копии». Приложение само напомнит о копии, если её не делали две недели.

## Как выпустить новую версию

1. После любой правки увеличьте `VERSION` в `sw.js` (например, `v1` → `v2`) и `APP_VERSION` в `app.js`.
2. Сохраните изменения в git и отправьте на GitHub (`git commit`, затем `git push`).
3. Через минуту GitHub Pages обновит сайт. Телефон подхватит новую версию при следующем запуске приложения.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Каркас страницы |
| `app.js` | Экраны, кнопки, хранение данных |
| `logic.js` | Расчёты: деньги, рабочее время и свободное время, отчёт, клиенты, резервная копия |
| `zip.js` | Архив резервной копии |
| `okna/` | Страница для клиентов со свободным временем |
| `style.css` | Оформление, светлая и тёмная тема |
| `sw.js` | Работа без интернета |
| `manifest.webmanifest`, `icons/` | Название и иконка для установки на телефон |
| `tests/` | Тесты расчётов |

## Проверка на компьютере

В папке проекта запустите:

```bash
python3 -m http.server 8765
```

Приложение откроется по адресу http://localhost:8765, тесты — по адресу http://localhost:8765/tests/. Остановить сервер: Ctrl+C.
